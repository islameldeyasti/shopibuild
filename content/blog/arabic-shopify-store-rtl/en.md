**Short answer:** a professional Arabic Shopify store is built in Arabic inside the theme, not with a translation app on top of an English store. That means correct RTL on every element, a readable Arabic font, copy written for Gulf shoppers, a separate URL per language, and an Arabic checkout. The difference shows up in trust and conversion from the first visit.

## Why a "translated" Arabic store loses sales

Shoppers notice quickly when a store is translated: arrows pointing the wrong way, broken prices, machine-translated text, menus opening from the wrong side. Every small flaw chips away at trust, and trust is what gets someone to enter their card number.

## 1. Real RTL, not just right-aligned text

Adding `dir="rtl"` to the page is only the first step. All of these need to mirror:

- **Menus** and the mobile drawer.
- **Sliders** and next/previous arrows.
- **Product images** and galleries.
- **Filters** and sorting on collection pages.
- **The cart drawer** and quantity buttons.
- **Directional icons** such as arrows and "back".

At the same time, some things should **not** mirror: numbers, phone numbers, codes and brand logos.

## 2. A readable Arabic font

Latin fonts that technically include Arabic often render weak Arabic letterforms. Choose an Arabic font designed for screens (such as IBM Plex Sans Arabic or Readex Pro) and watch for:

- A slightly larger size than English, since Arabic letters look smaller.
- More line height (around 1.7–1.9) for comfortable reading.
- Fast font loading so text doesn't appear late.

## 3. Copy written for Gulf shoppers

Literal translation from English doesn't sell. Write:

- Product names and descriptions in the words your customers actually use.
- Prices in AED or the local currency.
- Clear delivery information: how many days, and to which emirate.
- A return policy in plain language.

## 4. A separate URL per language (key for SEO)

Google needs to see the Arabic and English versions as separate pages, such as `/ar/products/...` and `/en/products/...`, linked with **hreflang** tags. Shopify does this automatically when languages are set up correctly. Translate the **URL handles** and the **meta titles and descriptions** for each product too.

More in [Shopify SEO in Arabic](/en/blog/shopify-seo-arabic).

## 5. Translation app, or built into the theme?

| | Translation app + RTL app | Arabic built into the theme |
|---|---|---|
| Speed | Usually slower (extra scripts) | Faster |
| RTL quality | Gaps in many elements | Complete and tested |
| Monthly cost | Ongoing subscriptions | None |
| SEO | Depends on the app | Full control |
| Control over copy | Limited | Full |

Shopify's free **Translate & Adapt** app is great for managing translated text, but it doesn't fix layout direction. RTL has to be solved in the theme itself.

## 6. An Arabic checkout

Shopify's checkout supports Arabic. Make sure that:

- Shipping messages and any payment methods you add are translated.
- Tabby, Tamara and Apple Pay options are clearly visible. See [Shopify payment gateways in the UAE](/en/blog/shopify-payment-gateways-uae).
- You place a full test order in Arabic on a phone before launch.

## Common mistakes in Arabic Shopify stores

1. Slider arrows pointing the wrong way.
2. Broken price and currency order, such as "AED 120" jumbled inside an Arabic sentence.
3. Buttons and menus left in English.
4. Banner images with English text on the Arabic version.
5. Customer emails and WhatsApp messages only in English.
6. The same URL for both languages with no hreflang.

## Pre-launch checklist

- [ ] Every page flows correctly right-to-left on mobile.
- [ ] The Arabic font is clear and readable.
- [ ] Prices are in AED and display correctly inside Arabic text.
- [ ] All buttons and messages are translated.
- [ ] A separate URL per language, with hreflang.
- [ ] A full test order in Arabic succeeds.

## FAQ

### Does Shopify support Arabic?
Yes. You can add Arabic as a store language, and the checkout supports it. RTL quality depends on the theme.

### Do I need an RTL app on Shopify?
Not if the theme is built properly for Arabic. RTL apps are a stopgap for themes without Arabic support, and they add slowdown and a monthly fee.

### Should I run separate stores for Arabic and English?
No. One store with two languages is easier to manage and better for SEO, with a separate URL per language.
